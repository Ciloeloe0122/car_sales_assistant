
# 红旗汽车智能销售助手

> 基于 Streamlit + DeepSeek API 的 AI 汽车销售助手

---

## 1. 项目概述

本项目基于 **Streamlit** 框架和 **DeepSeek API**，结合向量检索与 BM25 混合检索技术，实现智能选车推荐、车型对比、客户需求分析与销售管理等功能。

项目定位为汽车销售门店的数字化工具，帮助销售顾问提升服务效率和客户转化率。

**快捷体验地址**：https://carsalesassistant-fj6jxbn7zvn7zzldbydn7i.streamlit.app/

---

## 2. 功能清单

**智能选车对话**
- 多路召回检索（TF-IDF 向量检索 + BM25 稀疏检索）
- 支持自然语言提问，如“最贵的红旗车是哪款”、“H9和A6L哪个好”
- 流式 AI 对话，带上下文记忆（最近 3 轮）
- 车型参数卡片展示

**用户认证**
- 客户 / 销售双角色注册和登录
- 密码采用 SHA256 加密存储
- 客户登录后提问关联客户 ID，记录行为日志

**热门问题聚合**
- 基于向量相似度语义聚合
- 按提问频次降序排列，展示“大家都在问”

**销售工作台**
- 客户认领（从公海池认领客户到个人名下）
- 客户移除（将客户释放回公海池）
- AI 客户画像分析（车型偏好、预算范围、用车场景、核心诉求、对话回顾）
- 客户对话记录查询（基于 customer_id）

**数据持久化**
- SQLite 存储用户、客户画像、客户归属关系
- CSV 存储车型数据和用户交互日志

## 5. 安装与运行

**1. 安装依赖**

```bash
pip install -r requirements.txt
```

`requirements.txt` 内容：

```
streamlit>=1.35.0
pandas>=2.0.0
jieba>=0.42.1
scikit-learn>=1.3.0
rank-bm25>=0.2.2
openai>=1.0.0
python-dotenv>=1.0.0
markdown>=3.5.0
```

**2. 配置 DeepSeek API Key**

在项目根目录创建 `.streamlit/secrets.toml`：

```toml
DEEPSEEK_API_KEY = "your_deepseek_api_key_here"
```

或设置环境变量 `DEEPSEEK_API_KEY`。

**3. 准备车型数据**

将车型数据放入 `data/` 目录：

- `hongqi_data.csv`：红旗车型数据（必填）
- `competitor_data.csv`：竞品车型数据（可选）

CSV 格式要求（15 列，字段含逗号需用双引号包裹）：

```
品牌,车型,版本,指导价(万元),级别,能源类型,发动机,最大功率(kW),最大扭矩(N·m),变速箱,长*宽*高(mm),轴距(mm),主要配置,适用场景,亮点标签
```

**4. 启动应用**

```bash
streamlit run app_vector.py
```

## 6. 核心逻辑说明

**检索策略**

系统按以下优先级进行检索：

1. 多车型对比召回：检测用户输入中的车型关键词（如 H9、HS5、A6L），若 ≥ 2 个，则同时召回所有匹配车型
2. 数值排序兜底：检测“最贵/最便宜/最长/最大”等极值词，直接对 DataFrame 排序，保证准确
3. 多路召回：向量检索（TF-IDF char-ngram）+ BM25 检索，合并去重后取 Top 3

**热门问题聚合**

- 使用 TF-IDF 向量化问题
- 计算余弦相似度，相似度 ≥ 0.45 的问题归为同一话题
- 按话题总提问次数降序排列

**客户画像生成**

1. 从 `user_logs.csv` 中按 `customer_id` 读取历史对话
2. 拼接最近 30 条对话记录
3. 调用 DeepSeek API 生成结构化画像：车型偏好、预算范围、用车场景、核心诉求、对话回顾

**对话上下文**

系统保留最近 6 条历史消息（3 轮对话），超出部分自动截断。
